# QurbSpace 0.2.0-beta.11

A new look. Installed copies update themselves to this one.

## New

- **A new logo**: two circles, almost touching. Qurb means nearness: close,
  never merged. On the app icon, the notifications, the desktop window, the
  tray and the website.
- **QurbSpace, everywhere you read the name**: the apps' messages and titles,
  the window, the applications menu and the Windows installer.

## Downloads

Straight from the [README](https://github.com/saqibsiddiq/QurbSpace#get-the-beta),
or:

| Device | File |
|---|---|
| Android 8 or later | `QurbSpace-android.apk` |
| Linux | `QurbSpace-linux.AppImage`, or `QurbSpace-linux.deb` for Debian and Ubuntu |
| Windows 10 and 11 | `QurbSpace-windows-setup.exe`, **not yet run by us** |

## Known gaps

Unchanged from beta.10: deleting is for good; restoring a whole WhatsApp
backup to a new phone is not proven; Windows has not been run; Google Drive is
limited to the accounts added as testers until Google verifies the app. Full
list: [README](https://github.com/saqibsiddiq/QurbSpace#known-gaps).

Something wrong? [Report it](https://github.com/saqibsiddiq/QurbSpace/issues/new/choose).
