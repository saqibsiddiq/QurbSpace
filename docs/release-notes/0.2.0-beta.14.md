# QurbSpace 0.2.0-beta.14

Fast transfers both ways, and safer underneath. Installed copies update
themselves to this one.

## Faster

- **Fast transfers to your phone too.** A large file from your computer now
  goes over the same Wi-Fi link straight between the two: 256 MB at 36 MB/s,
  more than twice as fast as through the router (measured on a Galaxy S23 and
  a Linux laptop). As before, only when nobody is using the computer, and
  the link takes about half a minute to set up, so it pays off for the
  biggest files; anything else goes the usual way, no slower.
- **A link that can't be made is not tried again and again.** If the
  computer says no, or the link carries nothing, the file goes the usual way
  at once.

## Safer

- **Libraries with published flaws updated**: the code that handles network
  traffic (one flaw let anyone on the internet make a computer's network
  handling spin), compression, and certificate checks. The website was
  updated the same day. Every week now, a check looks for new ones.
- **The updater no longer unpacks zip files**, which QurbSpace never sends;
  updates are still checked against our signature before anything is
  installed.

## Fixed

- **Windows doesn't download the same update twice.** An update fetched and
  waiting for *Install update* is kept on disk, so restarting the computer
  first no longer fetches it again.

## Downloads

Straight from the [download page](https://www.qurb.cloud/download), or:

| Device | File |
|---|---|
| Android 8 or later | `QurbSpace-android.apk` |
| Linux | `QurbSpace-linux.AppImage`, or `QurbSpace-linux.deb` for Debian and Ubuntu |
| Windows 10 and 11 | `QurbSpace-windows-setup.exe`, tested on GitHub's Windows machines, not yet on a person's PC |

## Known gaps

Unchanged from beta.13: deleting is for good; restoring a whole WhatsApp
backup to a new phone is not proven; Windows' window has not been tried by a
person. Fast transfers take about 30 seconds to set up, and on Windows they
are built and not yet tried on a PC. One published flaw in the database
library waits for the Tor library QurbSpace uses to accept the fixed version
(decision 0093).

Something wrong? [Report it](https://github.com/saqibsiddiq/QurbSpace/issues/new/choose).
