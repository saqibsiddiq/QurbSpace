# QurbSpace 0.2.0-beta.12

Faster sends. Installed copies update themselves to this one.

## Faster

- **A file from your computer reaches your phone in seconds.** With the phone
  connected and both on the same Wi-Fi, about 4 seconds from the computer
  telling the phone to *sent you a file*, measured on a Galaxy S23. It was
  28 seconds.
- **Sharing from the phone starts sending at once**, without first checking
  for updates or backing up folders.
- **The notice comes when the file does**, not after the phone has tried
  every other device.

## Windows, tested

Every release now runs on GitHub's Windows machines and six Linux
distributions before you get it ([how](https://github.com/saqibsiddiq/QurbSpace/blob/main/docs/platforms.md)).
The first run found, and this release fixes:

- **Files sent to a Windows computer never arrived**: Windows refused each one.
- **A paired device could write outside the QurbSpace folder on Windows**,
  with a path naming another place. Refused now.
- A QurbSpace folder replaced by a new empty one could be taken for the old.

## Open to everyone

- **Google Drive for any Google account.** It was limited to the accounts we
  added as testers, who had to sign in again every week.

## Downloads

Straight from the [README](https://github.com/saqibsiddiq/QurbSpace#get-the-beta),
or:

| Device | File |
|---|---|
| Android 8 or later | `QurbSpace-android.apk` |
| Linux | `QurbSpace-linux.AppImage`, or `QurbSpace-linux.deb` for Debian and Ubuntu |
| Windows 10 and 11 | `QurbSpace-windows-setup.exe`, tested on GitHub's Windows machines, not yet on a person's PC |

## Known gaps

Unchanged from beta.11: deleting is for good; restoring a whole WhatsApp
backup to a new phone is not proven; Windows' window has not been tried by a person. A file waiting
in Google Drive reaches the phone at its next sync: Drive cannot wake a
phone. Full list: [README](https://github.com/saqibsiddiq/QurbSpace#known-gaps).

Something wrong? [Report it](https://github.com/saqibsiddiq/QurbSpace/issues/new/choose).
